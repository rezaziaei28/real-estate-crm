# MalekFlow (real-estate-crm)

A real estate management project built with Django, focused on managing properties, clients, visits, and agent collaboration.

## About This Project

The main idea is to build a CRM where real estate agents can manage their daily work in one place. Instead of using scattered notes and spreadsheets, they can track properties, customers, scheduled visits, and even collaborate with other agents.

The frontend design is ready, and I am currently working on the backend with Django.

## Tech Stack

- **Backend:** Python, Django
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS, Vanilla JavaScript
- **DevOps:** Docker, Docker Compose

## Current Status

The frontend is complete. I am now working on connecting it to Django, creating the database models, and building the authentication system. This is an ongoing project and I will update this file as I make progress.
